Core Foundation
Defining Information Security Preserving Value & Trust

🛡️ Core Definition

The practice of safeguarding information assets and processing infrastructure against unauthorized interception, modification, disruption, inspection, or destruction.

  • Broad Scope: Covers digital data, transit channels, cloud clusters, physical paper documents, and human interactions.
  • Business Impact: Prevents intellectual property theft, ensures regulatory compliance (GDPR, HIPAA), and protects brand reputation.
  • InfoSec vs CyberSec: InfoSec covers all data forms; Cybersecurity zeroes in on internet/digital attack surfaces.

⚠️ Real-World Breach Manifestations

  • Corporate Data Leak (e.g. Equifax): Exposure of 147M consumer records via an unpatched Apache Struts server vulnerability.
  • Critical Infrastructure Ransomware (e.g. Colonial Pipeline): Attack via single compromised VPN credential forced operational shutdown.
  • Targeted Phishing (e.g. FACC Aerospace): CEO fraud / BEC resulted in $54M fraudulent transfer via deceptive emails.
  • Defacement & Integrity Tampering: Unauthorized modification of state portal homepages and DNS records.
Strategic Governance
Information Security Management (ISMS) Continuous Operational Cycle

Information security is not a one-off product or isolated milestone—it is a perpetual governance lifecycle built upon the PDCA (Plan-Do-Check-Act) model (ISO/IEC 27001).

1. Plan

Establish security policies, scope critical assets, conduct risk assessments, and establish defense objectives.

➔

2. Do

Deploy baseline controls, configure technical safeguards, enforce access rights, and conduct workforce security training.

➔

3. Check

Audit system logs, conduct periodic vulnerability scanning, review compliance metrics, and test incident readiness.

➔

4. Act

Remediate identified security audit gaps, upgrade legacy defenses, update threat models, and drive continuous maturity.

The Three Governance Pillars

People (Awareness & Culture)  •  Processes (Policies, Incident Playbooks, Compliance)  •  Technology (Firewalls, SIEM, Cryptography, Identity Providers)

Core Pillars
The CIA Triad Architecture Tri-Fold Security Pillars

🔒 Confidentiality

Guaranteeing that data is accessible strictly to authenticated, authorized identities.

  • Mechanism: AES-256 encryption at rest, TLS 1.3 in transit.
  • Access Control: Role-Based Access Control (RBAC) and Multi-Factor Authentication.
  • Breach Example: Leaked medical diagnosis records or eavesdropped financial credentials.

🛡️ Integrity

Protecting authenticity, completeness, and accuracy from unauthorized alteration.

  • Mechanism: Cryptographic hashes (SHA-256), Digital Signatures, HMAC.
  • Access Control: Audit trails, database write permissions, immutable write-once logs.
  • Breach Example: Modifying student examination grades or altering transaction routing numbers.

⚡ Availability

Ensuring computing systems and services remain operational and accessible when requested.

  • Mechanism: Redundant hardware, automated failover, load balancing, offsite backups.
  • Access Control: DDoS traffic scrubbing, rate limiting, disaster recovery planning.
  • Breach Example: Ransomware locking core servers or a distributed SYN flood knocking down portals.
Security Vocabulary
Foundational Terminology & Risk Formulation Taxonomy of Risk
Concept Definition Practical Illustration
Asset Any item, system, or dataset possessing tangible/intangible organizational value. Customer database, cryptographic master keys, server clusters.
Vulnerability An inherent software flaw, design oversight, or misconfiguration in an asset. Unsanitized SQL input query, outdated SSL cipher suite, default password.
Threat & Actor Potential event or entity capable of exploiting a flaw to inflict harm. Nation-state APT, cybercriminal syndicate, disgruntled employee.
Exploit & Attack The deliberate technique or code execution used to violate security boundaries. Executing a buffer overflow script or triggering a privilege escalation bug.
Risk The calculated likelihood and severity of operational damage if a threat occurs. Risk = Likelihood × Impact (or Threat × Vulnerability × Asset Value).
Countermeasure Defensive control implemented to eliminate, mitigate, or detect threats. Web Application Firewall (WAF), Zero-Trust Architecture, MFA enforcement.
Psychological Exploits
The Human Aspect & Social Engineering Exploiting People Over Code

"Amateurs hack systems; professionals hack people." Social engineering targets human psychology—curiosity, fear, trust, and urgency—bypassing technological perimeter defenses.

🎣 Phishing

Fraudulent emails/SMS disguised as legitimate brands to harvest passwords, session tokens, or prompt malware downloads.

🎭 Pretexting

Fabricating an authoritative persona (e.g. IT support, auditor, C-level executive) to extract sensitive company credentials.

🪤 Baiting

Enticing victims with rewards: leaving weaponized USB drives in parking lots or offering pirated software installers bundled with Trojans.

🚪 Tailgating

Physically shadowing an authorized employee through secure badge doors under the guise of carrying boxes or forgetting a pass.

Countermeasures & Human Firewalls

Mandatory simulated phishing campaigns • Out-of-band verification protocol for money transfers • Hardware security keys (FIDO2/WebAuthn) immune to credential-harvesting phishing • Blameless reporting culture.

Infrastructure Hardening
Attacks on Internet-Facing Servers Defending Exposed Perimeters

Common Server Infiltration Vectors

  • Unpatched Known Vulnerabilities (CVEs): Automated bots constantly sweep the internet looking for outdated OpenSSL, Apache, or SSH daemons.
  • Credential Stuffing & Brute Force: Botnets running dictionary attacks against exposed RDP (Port 3389) or SSH (Port 22) endpoints.
  • Server Misconfiguration: Exposed cloud S3 buckets, open Elasticsearch databases, and default administrative logins.
  • Privilege Escalation & Persistence: Exploiting kernel bugs to gain root/system access followed by backdoor deployment.

Robust Defensive Hardening

  • Continuous Vulnerability Management: Automated patch deployment and periodic configuration scanning (OpenVAS / Nessus).
  • Perimeter Defense: Stateful inspection firewalls, IP allow-listing, disabling unused ports and legacy protocols (Telnet, FTP).
  • Access Modernization: Requiring VPN/WireGuard or Zero-Trust Network Access (ZTNA) with MFA before server shell access.
  • Host Hardening: Enforcing Principle of Least Privilege (POLP), SSH key-based authentication with disabled root login, and fail2ban.
Application Layer
Attacks on Web Servers & Applications OWASP Vulnerability Matrix
Vulnerability Attack Mechanism Effective Countermeasure
SQL Injection (SQLi) Inserting malicious SQL fragments into input fields to bypass auth or dump database records. Parameterized queries (Prepared Statements) & ORMs; strictly avoid string concatenation.
Cross-Site Scripting (XSS) Injecting malicious JavaScript into pages viewed by victims to steal session cookies/tokens. Context-aware output encoding, strict Content Security Policy (CSP), HTTPOnly cookies.
Directory / Path Traversal Using '../../etc/passwd' sequences to read unauthorized system files outside web roots. Strict filepath whitelisting, stripping traversal characters, running in chroot/containers.
Cross-Site Request Forgery (CSRF) Tricking an authenticated browser into issuing unwanted state-changing transactions. Anti-CSRF nonces/tokens, SameSite=Strict cookie attributes, re-authentication.
Web Defacement Unauthorized tampering of public page content, degrading organization credibility. File integrity monitoring (FIM), WAF, robust write-permission restrictions on web assets.
Availability Disruptions
Denial of Service (DoS & DDoS) Resource Exhaustion Strategies

Architecture & Attack Vectors

Goal: Paralyze service availability by exhausting bandwidth, CPU cycles, socket connections, or memory pools.

  • DoS vs DDoS: Single origin point vs. massive distributed botnets (compromised IoT devices, e.g. Mirai botnet).
  • SYN Flood (Layer 4): Floods TCP connection queues with spoofed SYN packets without completing the 3-way handshake.
  • UDP Amplification: Abuses misconfigured NTP/DNS servers to reflect 50x magnified traffic onto target IPs.
  • HTTP Flood (Layer 7): Saturates backend database compute by spamming heavy search queries or file downloads.

Multi-Tier Mitigation Framework

  • Traffic Scrubbing Services: Diverting incoming traffic through Cloudflare or Akamai to filter malicious surges before reaching origin.
  • SYN Cookies & Connection Dropping: Allocating zero kernel memory to half-open TCP states until final ACK arrives.
  • Rate Limiting & Geo-Filtering: Restricting request bursts per client IP using reverse proxy rate limiters (NGINX/Envoy).
  • Elastic Infrastructure: Auto-scaling compute clusters combined with globally distributed Anycast DNS routing.
Transit Security
Attacks on Network Systems In-Flight Data Interception

📡 Packet Sniffing

Passive eavesdropping of raw packet streams over unencrypted channels using tools like Wireshark/tcpdump.

Defense: End-to-end TLS encryption, SSH, IPsec VPNs.

🔀 Man-in-the-Middle

Interposing between two endpoints via ARP spoofing or DNS poisoning to secretly inspect and modify data in transit.

Defense: Dynamic ARP Inspection (DAI), HSTS, mutual TLS.

🔍 Port Scanning

Automated probes (Nmap) to discover open listening ports, daemon version banners, and discoverable entry points.

Defense: Network IDS/IPS, closing unused ports, port knocking.

📶 Rogue Access Points

Setting up "Evil Twin" Wi-Fi networks in public zones with identical SSIDs to siphon credentials from connecting victims.

Defense: WPA3-Enterprise, mandatory corporate VPN, 802.1X.

💡 Guiding Rule: Treat any physical or wireless network transmission line as inherently hostile unless authenticated and encrypted end-to-end.
Endpoint Threat Landscape
Malware Taxonomy & Endpoint Protection Client-Side Hazards

Propagation Variants

  • Virus: Parasitic malicious code requiring host executable modification and user execution to spread.
  • Worm: Self-propagating standalone malware utilizing network exploits to traverse devices autonomously (e.g. Conficker).

Payload Variants

  • Trojan: Disguised as legitimate utilities (e.g. PDF crack) while silently deploying backdoors.
  • Ransomware: Silently encrypts user files with asymmetric keys, demanding cryptocurrency for decryption.

Surveillance & Stealth

  • Spyware & Keyloggers: Exfiltrates browser history, keystrokes, webcam feeds, and screen captures.
  • Rootkits: Hooks into OS kernel APIs to conceal unauthorized processes from task managers.

Holistic Endpoint Defense Strategy

Enforce Next-Gen Antivirus (EDR) with behavioral heuristics • Principle of Least Privilege (run as standard user, not Administrator) • Rapid OS & browser patching • Application Sandboxing • Immutable off-site 3-2-1 backup strategy against ransomware.

Physical Security
Lost, Stolen & Physically Compromised Devices The Mobile Boundary

High-Impact Asset Risks

Laptops and smartphones carry active authentication tokens, corporate emails, and session cookies—acting as immediate entry portals.

  • Direct extraction of plaintext local files via external OS boot.
  • Session hijacking into enterprise cloud storage and SSO providers.
  • Bypassing biometric sensors if unlock fallback PINs are simplistic.
  • Exposure of stored 2FA SMS and authenticator apps on unlocked devices.

Incident Response Lifecycle

  • Proactive Safeguards: Mandatory Full Disk Encryption (BitLocker / FileVault / LUKS), enforce complex alphanumeric passcodes, short display auto-lock timers (≤2 min).
  • Enterprise MDM Controls: Enrolling devices in Mobile Device Management (MDM) with remote lock and cryptographic wipe capability.
  • Post-Loss Immediate Action: Remotely invalidate active OAuth tokens, reset master enterprise passwords, and trigger remote factory wipes immediately.
Applied Scenario
Synthesized Case Study: University Credential Breach Connecting Theory to Practice

Scenario Flow

A student receives an urgent SMS: "Your university grade portal will be deactivated in 30 minutes. Verify credentials here: university-portal-auth.net."

  • The student clicks the link and enters their student ID and password.
  • The attacker uses harvested credentials to access the internal campus grade database.
  • The attacker alters their failed course grade to an "A" and drops grades for other students.

Mapping to Course Concepts

  • Threat Vector: Social Engineering (Smishing + Phishing).
  • Vulnerability: User susceptibility to urgency + Missing Multi-Factor Authentication (MFA).
  • CIA Triad Violations:
    • Confidentiality: Student private records exposed.
    • Integrity: Unauthorized alteration of grade records.
    • Availability: Portal locked for emergency maintenance.
  • Mitigation: Enforce FIDO2 Hardware MFA keys, domain-based email/SMS validation, and database audit logging.
Summary & Principles
Key Architectural Takeaways Guiding Security Principles

Defense in Depth

Never rely on a single perimeter wall. Layer defenses across firewalls, host hardening, encryption, and endpoint detection.

Zero Trust Posture

"Never trust, always verify." Treat both internal and external network traffic as potentially compromised; enforce continuous verification.

Human Empowerment

Technology is insufficient if human psychology is neglected. Regular security training transforms people into an active defense layer.

The Core Rule of Information Security

Security is a dynamic, continuous process—not a static destination. Continuous assessment, prompt patching, least privilege, and proactive incident response maintain the balance of Confidentiality, Integrity, and Availability.
