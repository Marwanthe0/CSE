# Computer Graphics Lab Experiments 🎨

Comprehensive study guides, step-by-step mathematical derivations, and OpenGL/GLUT C++ implementations for all 14 Computer Graphics laboratory experiments.

---

## 📁 Repository Structure

Each experiment is organized into its own dedicated folder containing:
* **C++ Source Code (`.cpp`)** – Clean, tested OpenGL/GLUT implementation.
* **Lab Study Guide (`.md`)** – Plain-English explanation, complete math derivations, algorithms, trace tables, and viva questions.
* **Printable PDF Guide (`.pdf`)** – Formatted, publication-ready PDF document ready for printing or offline study.

## 🛠️ How to Compile & Run (macOS)

Navigate into any task folder and compile using `g++` or `clang++`:

```bash
cd 1_DDA_line_drawing
g++ 1_DDA_line_drawing.cpp -o test -framework OpenGL -framework GLUT
./test
```
